# Naechtigungsprognose
Das Modell erstellt eine Nächtigungsprognose für österreichische Tourismusregionen. Diese erfolgt auf Monats- und Tagesbasis.  Das Modell wurde von einem Team von Joanneum Research, der TU Wien und der AAU in R implementiert und wird mit Unterstützung der Österreich Werbung frei zur Verfügung gestellt.
